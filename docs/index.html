Linux x86_64 and aarch64 · animation-free · no telemetry

Everything between the download and Play

A focused launcher, not a storefront.

Library and covers

Instant search, game icons, Steam covers and play time. Press Enter to open a game, Esc or your mouse Back button to return.

Fix detection

OnlineFix, FreeTP and EOSFix files are detected and patched: AppIDs, ExtraProtection, Photon, winmm/dlllist and the SteamFix bypass.

Proton manager

Browse GE-Proton releases from GitHub, download, unpack and remove builds. Incompatible CPU architectures are filtered out.

Steam integration

Starts Steam and waits for sign-in when needed, injects the overlay, and supports Steam Linux Runtime and native Wayland.

Add any way you like

Add an extracted folder, a RAR archive, a FreeTP installer, or download a game from a Hydra/OnlineFix JSON source with aria2c.

Wine tools

Open winecfg, task manager, explorer, regedit, a command prompt or Winetricks in the game prefix. Run any .exe there too.

A game page that gets out of the way

No stretched cover art. Just the game icon, the facts, and the controls you need.

  • Back arrow, mouse Back/Forward, Esc and Alt+←/→
  • Play, Settings, Debug, Wine tools, folders, run an .exe, logs
  • Per-game Proton, prefix, arguments, environment and DLL overrides
  • Desktop and application-menu shortcuts, play time and Steam links

Install

One compiled binary. No bundled runtime.

Release binary

chmod +x rivet-linux-x86_64
./rivet-linux-x86_64

Use rivet-linux-aarch64 on ARM64. Qt 6, Steam, unrar, 7z, tar and aria2 are needed for the corresponding features.

Nix

nix run github:ne1i/rivet-launcher

Enable nix-command flakes first. The flake is built and tested in CI.

From source

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
sudo cmake --install build

Arch packaging for rivet-launcher-git is in packaging/aur. It is not published on AUR yet.

Configuration

One versioned JSON file, not a pile of INI sections.

~/.config/rivet/config.json
~/.local/share/rivet/

Settings, games, launch arguments, environment variables and feature flags all live in a structured document. On first start Rivet migrates an existing ~/.config/OFME-Linux library automatically and leaves the old files untouched.

"environment": {
  "LC_ALL": "fr_FR.UTF-8"
},
"steam": {
  "app_id": "12345",
  "overlay_app_id": "480"
}

Covers and icons are copied to ~/.local/share/rivet; existing Proton and prefix folders are reused in place.
